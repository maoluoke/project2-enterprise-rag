# 周报生成技能

## 流程

1. **确定范围**：从用户问题提取项目名/时间范围；缺时间范围时默认"近7天"
2. **广度检索**：围绕主题调用 2-3 次 `kb_search`，覆盖：
   - 项目名 + 进展/里程碑
   - 项目名 + 问题/事故/阻塞
   - 相关人名 + 本周动作
3. **按模板组织输出**：

```
## 本周进展
- （每条一行，标注 [doc_id]）

## 问题与风险
- （每条一行，标注 [doc_id]）

## 下周关注
- （基于检索到的 TODO/计划项；没有则省略本节）
```

## 规范

- 全文不超过 300 字
- 只写检索到的事实，不编造进展
- 若某项目知识库中信息过少，直接说明"近N天知识库中无该项目动态"
